# 朝倉柊太 Portfolio

Unityエンジニア・3Dデザイナー 朝倉柊太のポートフォリオサイト。
HTML / CSS / JavaScript（ES Modules）で動作する静的サイトです。ビルドや外部ライブラリは不要です。

作品一覧では画像・概要・担当内容を同じ順序で確認でき、詳しい実装や制作分担は作品詳細で読めます。プロフィール・使用技術・職務経験も掲載しています。

## 公開先

- 作業・公開ブランチ：`feature/portfolio-site`
- `main` から作業ブランチを作成。Unity・資料のリポジトリとは独立しています。

GitHubの Settings → Pages で、Source を「Deploy from a branch」、Branch を `feature/portfolio-site`、フォルダーを `/ (root)` に設定します。公開ブランチを変更する場合は、この設定も更新してください。

## 内容

- もぐもぐマネジメント：2026年〜現在、個人で開発中。約2分25秒の紹介動画。食品管理／育成の2つのモード、操作の流れ、実装状況
- SalesManagement21：専門学校の授業「システム開発演習」で2022〜2023年に6名のチームリーダーとして制作。受発注・売上・在庫などの管理をC# / Windows Forms / Entity Framework / SQL Server LocalDBで実装
- バーチャルミーティング（大阪オフィス）：2024年、VRIA研修後の待機期間中に上司の提案で社内チーム制作。朝倉はBlender / GIMPによる3D・画像デザインを担当。Unity / C# / Gitを用いたチーム開発作品
- アロワナの3Dモデル：2025年3〜4月、業務外の共同自主制作。朝倉の魚体・アニメーションを中心に紹介。先輩デザイナーと制作した水槽との分担、画像、4本の動画を掲載
- バーチャル万博の案内所、ファッションショー、盆踊り大会、ARミャクミャクとクイズ：業務で携わったチーム制作。盆踊りの大屋根リング版は会場の単独制作とエンジニアとの連携を紹介。ARミャクミャクのボーン・アニメーションとクイズAR版の担当を明記
- バーチャル万博 閉幕式会場：2025年9月、約1週間で会場全体と落ち葉のギミックを単独制作
- ハイポリゴン・ベッドモデル：2025年4〜5月、休日などを利用した個人自主制作（自己研鑽）
- プロフィール、スキル、職務経験、学歴・資格、連絡先
- 作品目次から、アプリ開発2件・3Dアセット2件・XR・イベント作品6件の各グループへ移動
- 共有可能な作品詳細URL、次の作品への移動、スマートフォン用の目次
- 紹介動画は「紹介動画を見る」から展開して手動再生。閉じると再生を停止し、`#demo` へのリンクからは動画欄を展開
- アロワナの動画はサイト内のMP4を手動再生。動画欄や作品詳細を閉じた時、次の作品へ移動した時に停止
- 作品詳細を開いた時と次の作品への移動時は、タイトルにフォーカス。閉じると元の操作位置へ戻る
- 「動きを止める」でスクロール時の登場演出を停止し、選択を端末に保存。端末の動きを減らす設定にも対応
- 全10作品を常に表示し、印刷時も全作品を掲載

作品目次は `#works`、各グループは `#app-projects`・`#asset-projects`・`#xr-projects` です。目次のリンクから該当するグループへ移動でき、閲覧中のグループを示します。

## 更新する場所

| ファイル | 内容 |
| --- | --- |
| `index.html` | 基本情報、作品一覧、職務経験、連絡先、クレジット |
| `app.js` | 各作品の詳細、ダイアログ、動画の開閉、目次の現在位置、モバイルメニュー |
| `styles.css` | 色・余白・文字サイズ・レスポンシブ表示 |

| `assets/video/mogumogu-introduction-20261111.mp4` | 2026年11月提供の改訂版紹介動画（BGMを保持） |
| `assets/video/mogumogu-introduction-ja.vtt` | 動画内容の日本語説明字幕 |

連絡先メールは朝倉の希望により掲載しています。住所・電話番号・生年月日、履歴書・職務経歴書のPDF原本はリポジトリに含めていません。

CSS・JavaScript・faviconの参照には内容ハッシュのバージョンを付けています。更新時にはindex.htmlのクエリ値も変更し、前のキャッシュが作品情報を表示し続けないようにしてください。

## ローカルで確認

```sh
python -m http.server 4173
```

Pythonがない場合は、任意の静的HTTPサーバーを使えます。ES Modulesを使用するため、HTMLファイルの直接ダブルクリックではなくHTTP経由で開いてください。

ブラウザーで `http://localhost:4173` を開きます。公開先のサブディレクトリでも動くよう、ローカル素材のパスは相対パスです。
